# Executable Evidence Contracts for Signal-Grounded Verification of Wearable Sensor Claims

This repository contains **code and reproducibility materials** for the
accompanying ICASSP 2027 paper. It does **not** contain the submitted
manuscript, LaTeX source, or compiled PDF (those ship with the CMS submission
package).

Public-safe release tag: `icassp2027-public-release-v2`.
See [`PUBLIC_PROVENANCE.md`](PUBLIC_PROVENANCE.md): this tree is **derived from**
private scientific commit `7c4681eb2be52929793772a279a7a0fe4a3c85ee`; the public
SHA is not that commit. Item-level sealed confirmatory artifacts are
intentionally withheld. Aggregate paper numbers are in
[`PAPER_AGGREGATE_RESULTS.md`](PAPER_AGGREGATE_RESULTS.md).

The question this repository is meant to answer is: can another researcher
reproduce the **non-sealed** stack (kernels, contracts, Kleene, the
deterministic source-grounding compiler, compiler adapter, unused-window
scripts) and mechanically check the headline aggregate numbers?

## Quick check

```bash
pip install -r requirements.txt
python reproduce.py --tables            # checks E1/E2/H2B aggregate cells against the paper
python reproduce.py --verified-results  # hash-checks non-withheld frozen artifacts
python reproduce.py --all-available     # tables + verified-results + figures + paper (paper/figures are no-ops here; see below)
```

`reproduce.py --paper` and `--figures` report `NOT_APPLICABLE` in this
code-only release because the manuscript source is not distributed here.
There is intentionally **no** `--all` mode: the official $448$- and
$768$-surface sealed language holdouts must not be rescored.

## Project description

A sentence about a wearable IMU recording is compiled into an executable
program over eight frozen digital-signal-processing primitives, licensed by
named-channel evidence contracts, measured with textbook DSP kernels, and
adjudicated under Strong Kleene logic as `SUPPORTED`, `CONTRADICTED`, or
`UNVERIFIABLE`. The semantic compiler specifies what to measure; it never
observes the waveform and never writes the verdict.

The method verifies structured wearable-IMU claims inside a frozen
eight-primitive ontology. It does not solve unrestricted sensor language.

## Environment setup

- Python 3.10+
- `pip install -r requirements.txt` (NumPy, SciPy, pandas, pytest, python-dateutil)
- [Ollama](https://ollama.com) on `127.0.0.1:11434` with `qwen3:8b`
  (`ollama pull qwen3:8b`) for any step that calls the semantic compiler

Kernel, contract, Kleene, and regression tests do not require Ollama.

```bash
pip install -r requirements.txt
python scripts/reproduce_all.py
python scripts/reproduce_first_principles.py
python scripts/reproduce_p2c.py
python scripts/reproduce_oracles.py
python scripts/reproduce_lag.py
python -m pytest tests -q
```

These commands check frozen kernels, contracts, Kleene tables, analytic lag
oracles, and the evaluation-only lag time-base flag. They do **not** rescore
the paper tables, do not open any sealed holdout, and do not require Ollama
or the raw IMU corpora.

Production lag support is physical: \(L(f_s)=\lfloor T_{\max} f_s\rfloor\) with
\(T_{\max}=0.300\)\,s, and \(\tau=1000\,\hat\ell/f_s\) milliseconds. Dominant
frequency is \(\hat k f_s/N\) Hz. Periodicity is
\(\max |R_{xx}[\ell]|/R_{xx}[0]\) on \(\ell\in[3,N/2)\).

Raw corpora are **not** shipped (licensing). Download them separately and

## Reproduction instructions

Advertised no-data checks (must pass on a clean clone):

```bash
python scripts/reproduce_all.py
python scripts/reproduce_first_principles.py
python scripts/reproduce_p2c.py
python scripts/reproduce_oracles.py
python scripts/reproduce_lag.py
```

Full-corpus `run_*.py` jobs below need the public IMU datasets locally.
They are not re-run to obtain new paper numbers. Each invocation is
independent. Use `--help` for phases. Outputs go under `results/<phase>/`.

```bash
# Independent DSP validation, benchmark construction, V3 challenge
python scripts/run_p2.py
python scripts/run_p2r.py

# Mechanism baselines (B1/B2/B3/B5), language shift, HARTH, margin probes
python scripts/run_p3.py --phase all

# Evidence-contract construction and EC-blind
python scripts/run_p3r_ec.py --phase construct
python scripts/run_p3r_ec.py --phase eval-blind

# Language-shift and HARTH closure cells
python scripts/run_p3c.py --phase ls-build
python scripts/run_p3c.py --phase ls-eval
python scripts/run_p3c.py --phase harth-build
python scripts/run_p3c.py --phase harth-eval

# Compound (AND/OR/IF-THEN) semantic development cells
python scripts/run_p3cr.py --phase sem-build
python scripts/run_p3cr.py --phase sem-dev

# Physical-semantics and evidence-trust cells (need local PAMAP2 unused windows)
python scripts/run_p2_phase2.py
python scripts/run_p2_phase2_exp2.py
python scripts/run_p3_evidence_trust.py
# Optional: unused-window resampling script (not a sealed confirmatory run)
# python scripts/p4_final/physical_invariance.py
```

Sealed confirmatory item-level data (holdout sentences, gold JSONL, compiler
records) are **not** in this repository and must not be reconstructed from it.
The paper reports the withheld-set aggregates: gold-program and full-path
\(828/828\), FCR \(0/92\), FA \(0/736\), on the direct vs-threshold family,
plus two independently sealed unseen-language holdouts (unlicensed FCR
\(16/64\) and \(102/192 \to 47/192\) before/after deterministic source
grounding). See [`PAPER_AGGREGATE_RESULTS.md`](PAPER_AGGREGATE_RESULTS.md)
for the full set and `python reproduce.py --tables` to check the
non-item-level cells mechanically.
